# Приемателни сценарии — проект

Сценариите следват одобрения договор за глобалния Turso каталог и canonical directory identity. Наличието им не означава изпълнени тестове.

| ID | Сценарий | Очакване |
| --- | --- | --- |
| K01 | Няма каталог/последен проект | Празен каталог и welcome; без implicit запис в project directory |
| K02 | Добавяне на достъпна директория | Един устойчив запис, стабилен ID, правилно име/път |
| K03 | Повторно добавяне на същия път/alias | Existing outcome със същия ID; без дубликат според приетата normalization политика |
| K04 | Две различни директории с еднакво име | Различни регистрации, различими чрез път |
| K05 | Празен път, файл или липсваща директория | Конкретна диагностика; без каталог mutation |
| K06 | Недостъпна директория или грешка при canonicalization | Запазена техническа причина; няма fallback към cwd/друг проект |
| K07 | Рестарт с достъпен последен проект | Възстановен проект за съответното приложение; без стартиране на scripts/агенти |
| K08 | Последен проект липсва/преместен/недостъпен | Каталог и разбираема причина; регистрацията остава; не се отваря друг проект |
| K09 | Двете приложения имат различен последен проект | Preferences остават отделни; текущите екрани не се синхронизират |
| K10 | Конкурентни registrations | Без изгубени записи; едновременен duplicate води до една регистрация |
| K11 | Отказ от запис или cancellation | Без частичен каталог; завършените ефекти остават различими; Retry започва с прочит |
| K12 | Регистрация успява, preference се проваля | Проектът остава регистриран; видимо непотвърдено last-opened; Retry не дублира |
| K13 | Повреден/бъдещ каталог или dangling last-opened ID | Без изтриване/тиха миграция; отделна диагностика; оригиналните данни се запазват |
| K14 | Cancel в directory input/chooser | Без регистрация или промяна на last-opened |
| K15 | TUI/GUI, en/bg, тесен размер, дълги пътища | Четими списък/причина/действия и достъпен фокус; views не извършват effects |
| K16 | Самостоятелно стартиране/затваряне | Всяко приложение работи без другото; help/version остават без startup ефекти |

За filesystem tests се използват временни директории; потребителски проекти и реални агенти не участват. Case sensitivity, symlink и permissions се проверяват според наличните платформи, с отделно отчетени пропуски.
