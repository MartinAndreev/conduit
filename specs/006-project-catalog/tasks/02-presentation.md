# B — добавяне и възстановяване в отделните приложения

Статус: чака приемане на application групата и одобрение на UI задачите.

TUI и GUI имат отделни owners. Споделят приетите application операции и i18n keys; не споделят runtime избор или управление на прозорци.

Обхват: input/chooser за съществуваща директория, запазен списък, минимален project home след добавяне/начално възстановяване, Cancel/Retry и структурирани диагностики. Няма навигация за превключване на активен проект по време на работа.

Изходните [макети](../../004-project-navigation/screens/README.md) са ориентир. Контроли извън този обхват остават unavailable; макет не разрешава допълнителна функционалност. Точният минимален home се преглежда преди implementation.

Проверки K14–K16, реални captures с synthetic fixtures, keyboard/focus/resize, английски/български и изолирани native build-и. Views нямат file/database effects. Не стартирай реални агенти или инсталатори. Без commit без изрична заявка.
